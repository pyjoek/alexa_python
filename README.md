# Alexa Python

Simple voice assistant experiments.

## Current version

The main working version is inside the **`new_version/`** folder.

It is a fully standalone local voice assistant that uses Ollama as the brain.

```bash
cd new_version
pip install -r requirements.txt
python assistant.py
```

See `new_version/README.md` for full details.
